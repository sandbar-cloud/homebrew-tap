# Sandbar Homebrew Tap

Homebrew formulae for [Sandbar](https://sandbar.cloud) tools.

## Install

```sh
brew install sandbar-cloud/tap/sandbar
```

Or add the tap first, then install by name:

```sh
brew tap sandbar-cloud/tap
brew install sandbar
```

## Formulae

- [`sandbar`](https://github.com/sandbar-cloud/sandbar-cli) — CLI for deploying static sites to Sandbar.

## Updating

Formulae in this tap are generated by [GoReleaser](https://goreleaser.com/) —
do not edit them by hand. Each release of `sandbar-cli` pushes an updated
formula via the `Deploy` workflow.
